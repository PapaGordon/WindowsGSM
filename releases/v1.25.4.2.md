# MeFriendos WindowsGSM v1.25.4.2

Vanilla Minecraft Java now uses our Minecraft_Java implementation. You can also install a plain NeoForge server without a modpack. ATM10 stays available as its own entry.

- Vanilla downloads the official Mojang server, verifies it before replacing files and reads its version without needing a first start. Existing worlds, settings and JVM arguments are kept. Failed runtime updates can restore the previous files.
- NeoForge has its own fox icon, downloads the official installer and checks its SHA-256. Choose a NeoForge version family or pin an exact version. Updates are prepared separately and keep a full backup of the previous server files.
- Vanilla, NeoForge and ATM10 use separate per-server game/query firewall rules. SteamCMD no longer adds an unconditional firewall allowance.
- Steam passwords can now be stored encrypted for the Windows user running WGSM. Plaintext account files still work.

## Download and update

Use **WindowsGSM-v1.25.4.2-win-x64.zip** for the EXE, password helper, instructions and license notices. The separate **WindowsGSM.exe** is the same self-contained Windows x64 build. You do not need to install .NET separately. Minecraft and NeoForge still need the matching Java installation.

Quit WindowsGSM before replacing the EXE. Back up your installation and keep your existing servers, plugins and configuration folders. The release ZIP contains no server data or Steam credentials.

## Encrypt your Steam password

1. Extract the ZIP into your WGSM folder after updating the EXE.
2. Run **Encrypt-SteamPassword.cmd** as the same Windows user that runs WindowsGSM.
3. Enter your Steam login name, then your password at the hidden prompt.
4. Wait for the confirmation, then start WindowsGSM again.

The helper replaces the readable password in `bin/steamcmd/userData.txt` with an encrypted value. It does not create a plaintext backup or sign into Steam. If the file does not exist yet, click **Set Account** in WGSM's installation screen once to create it, then close WGSM and run the helper.

The encrypted password belongs to that Windows user on that machine. After moving WGSM or changing its Windows account, run the helper again. Existing backups of the old account file may still contain the readable password.

This protects the saved file, not a compromised administrator account. WGSM still gives the decrypted password to SteamCMD as a process argument. Steam Guard may still require confirmation, and this does not add automatic DayZ Workshop updates.

## Checked locally

Both Vanilla implementations passed their checks with the official Minecraft 26.3 download. NeoForge passed its fixture checks and a separate install with the official NeoForge 21.1.265 installer and Java 21. The password helper was checked with synthetic credentials. Integration and DayZ console tests use isolated fixtures. The release EXE is also checked through its own startup and plugin loader before upload.

Live multiplayer, unattended Steam login and production firewall behavior were not tested for this release.
