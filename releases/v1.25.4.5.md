Fixes the ATM10 update still stopping with duplicate mod ID `computercraft` in the two CC:Tweaked JARs supplied by the server pack.

The earlier WGSM check was stricter than NeoForge's own mod discovery. NeoForge groups candidates by their first mod ID and selects the newest version before checking for remaining conflicts. WGSM now preserves candidates supplied by the incoming pack instead of rejecting them. Keep your original ServerFiles ZIP unchanged; there is no need to remove a CC:Tweaked version from it.

Additional mods with separate IDs remain installed. Older leftover versions absent from the new pack can still be replaced by the new pack's mod IDs; an overlapping additional bundle with extra IDs remains a conflict. Backups, configuration preservation and the BCC version fix remain in place.

For the MeFriendos fork, replace WindowsGSM.exe using this release. Standalone users can use ATM10 v0.1.14 on another compatible WGSM host. The ZIP includes the password encryption helper and existing server/Workshop setup guides.

Validation: 43 update-safety checks for each ATM10 source, the full WGSM solution build and nine checks against the final self-contained EXE. The final EXE test exercises both an obsolete installed CC:Tweaked version and both versions supplied by the pack. No live Minecraft server or single-player crash diagnosis is claimed.

Loader behavior: [NeoForge/FML for Minecraft 1.21.1, UniqueModListBuilder](https://github.com/neoforged/FancyModLoader/blob/1.21.1/loader/src/main/java/net/neoforged/fml/loading/UniqueModListBuilder.java).
