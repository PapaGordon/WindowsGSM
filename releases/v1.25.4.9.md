The DayZ and Arma 3 Workshop updater filled the drive and could keep a server offline. Every start copied all Workshop mods again and kept the old copies as a new backup in `serverfiles\.wgsm-workshop-backups`, which was never cleaned up. On a full drive SteamCMD could also lose its saved login, so the next start asked for Steam Guard again. If nobody confirmed it, the server did not start. This update fixes both.

- Only mods whose files changed are replaced. A restart without mod updates copies nothing and creates no backup.
- Only the latest backup is kept. Older ones are deleted after the next successful update.
- The update needs at least 5 GB free on the drives of the server, the download cache and SteamCMD. With less space it is skipped, so SteamCMD keeps its saved login.
- If the Steam login, the download or the replacement fails, the server starts with the mods that are already installed. The WGSM log shows a `[Notice]` with the reason. The start is only cancelled when a configured mod folder does not exist yet, the mod list is invalid or a recovery is pending.
- If SteamCMD exits before it reaches the login, the download is retried once. A failed login is not repeated, so Steam Guard asks only once. Parallel Workshop jobs wait up to ten minutes for each other.

Old backups from earlier versions are removed after the first successful mod update with this version. To free the space right away, stop the server and delete `serverfiles\.wgsm-workshop-backups`, unless `configs\workshop-state-<app ID>\pending.txt` exists. Keep `configs\workshop-state-<app ID>\download`, so SteamCMD only downloads changes.

To update, close WindowsGSM, back up the old EXE and replace it with the new `WindowsGSM.exe`, or use the ZIP. Your servers and saved credentials stay as they are.

Tested: Release build, 51 Workshop checks, 130 built-in server checks, 11 encrypted-password checks and 115 DayZ console checks. On our live server, a scheduled DayZ restart with 17 Workshop mods used SteamCMD's saved login without a Steam Guard prompt, got a download receipt for every item, left the unchanged mods alone without creating a backup and was back up after 35 seconds. The start with installed mods after a failed Steam login and the replacement of an updated mod were checked with test fixtures only.
