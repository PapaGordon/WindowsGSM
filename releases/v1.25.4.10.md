Project Zomboid always started with 16 GB of RAM, and the only way to change that was to edit the code. Now you can set it in the start parameters in WindowsGSM, for example `-Xmx8g -servername MyServer`. WindowsGSM hands `-Xms` and `-Xmx` to Java and everything else to Project Zomboid. If you only set one of them, it's used for both. Without them the server keeps its 16 GB, so existing servers behave exactly as before.

The docs are rewritten and easier to follow. Every built-in game now has its own guide: Arma 3, ATM10, DayZ, Enshrouded, Farming Simulator, Minecraft, NeoForge, Project Zomboid, SCP: Secret Laboratory and Valheim. The overview page lists what each game needs before the first start. The guides now also mention things that weren't written down before, for example that Max Players and Map aren't passed to Arma 3, and that Farming Simulator takes all its settings from the GIANTS web panel.

To update, close WindowsGSM, keep a copy of the old `WindowsGSM.exe` and replace it with the new one, or use the ZIP. Your servers and saved credentials stay as they are.

Tested: Release build, 188 built-in server checks including the new Project Zomboid memory checks, 51 Workshop checks, 11 encrypted-password checks and 115 DayZ console checks. The memory setting wasn't tested with a running Project Zomboid server yet.
