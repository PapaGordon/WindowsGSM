Fixes the reported ATM10 update conflict between `cc-tweaked-1.21.1-forge-1.113.1.jar` and `cc-tweaked-1.21.1-forge-1.120.2.jar`.

The incoming pack replaces older JARs that provide the same pack mod IDs, including leftovers missing from the ownership inventory. Additional mods with separate IDs remain installed. A bundle with both pack IDs and extra IDs still stops the update so its extra mods cannot silently disappear. Previous server files remain in the update backup.

DayZ and Arma 3 also gain optional Workshop updates before every start. Create `servers/<ID>/configs/WorkshopMods.cfg` with `itemID|@Folder|mod` or `itemID|@Folder|servermod` entries. Steam subscriptions alone are not a server mod list. Downloads are prepared together, signing keys are managed separately from manual keys, and failures cancel startup. See the included WORKSHOP.md for setup, backups and recovery.

The ZIP contains the self-contained Windows x64 EXE, password encryption helper, documentation and artwork credits. You can also replace only WindowsGSM.exe in an existing installation. Stop WindowsGSM and the game servers first, keep your existing server/config/bin folders, then use the new EXE. Built-in ATM10, DayZ and Arma changes require updating the EXE.

Validation: 41 ATM10 update fixtures for each built-in and standalone source, Workshop download/deployment/rollback fixtures, plugin API and encrypted credential checks, DayZ console regression checks, full solution build and a published EXE/plugin-loader smoke check. Real Steam authentication and live game-server joins were not tested.
