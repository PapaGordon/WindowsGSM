Garry's Mod could crash after loading with `CTextConsoleWin32::GetLine: !GetNumberOfConsoleInputEvents` when Embed Console was enabled. This hotfix fixes that launch problem.

Source servers now keep their own Windows console, and WGSM shows the output from `console.log` or `console.txt` in the embedded console. Commands and stopping the server still use the native window. WGSM adds `-condebug` automatically when Embed Console is enabled. Keep the default log filename; old log entries stay in the file and are skipped on restart.

Project Zomboid and SCP: Secret Laboratory now use their original game icons. The other game images were checked too. ATM10, DayZ and NeoForge keep their native artwork, and the FS22/FS25 icons stay as they were.

To update, close WindowsGSM, back up the old EXE and replace it with the new `WindowsGSM.exe`, or use the ZIP. Then start Garry's Mod with Embed Console enabled. You do not need to reinstall the server.

Tested: Release build, 23 Source console checks inside the final EXE, 115 existing DayZ console checks and all 55 game-icon mappings. The old input-handle error was reproduced in the test and passes with the fix. Garry's Mod startup with Embed Console enabled was also confirmed on the live server.
