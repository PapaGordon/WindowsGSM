Fixes the ATM10 update retaining an old Neo Vitae material definition and causing clients to disconnect with unknown registry keys for bauxite, iesnium, titanium, tungsten, generic xychorium and yellorite.

The old file-level config preservation treated `config/neovitae/materials.json` like a local server preference. This file defines client-visible items, so it now follows the selected original server pack. Other settings keep their normal merge behavior, and additional mod JARs remain preserved. See `pack-managed-configs.txt` and the original file under `serverfiles` in the full update backup.

Install the new EXE, stop the ATM10 server, then click Update using the matching original ServerFiles ZIP. A manual update can repair the material definition even if WGSM already reports the same pack version. Restart the server after updating and use the same ATM10 client version.

ATM10 intentionally removed these material definitions in its earlier pack update. Existing stacks of those Neo Vitae material items may be lost when the updated world loads. Keep the world/update backup before starting. Do not delete the world or remove Neo Vitae itself. [Official pack change and world-impact notes](https://github.com/AllTheMods/ATM-10/pull/4370).

Validated by reproducing the failure with the official 8.1 and 8.3 material files, 50 update-safety checks per ATM10 source, the full WGSM build and eleven checks inside the final self-contained EXE. Live multiplayer joins and single-player crashes were not tested here.

The standalone equivalent is ATM10 v0.1.15. The previous fix preserving both pack-supplied CC:Tweaked candidates remains included; keep the original ZIP unchanged.
